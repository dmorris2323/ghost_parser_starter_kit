    import pandas as pd
    from pathlib import Path

    def score_fusion(fused_file="fused_output.csv"):
       fused_path = Path(fused_file)
       if not fused_path.exists():
          print(f"❌ File not found: {fused_path.resolve()}")
          print("➡️ Create fused_output.csv in src/ and rerun.")
          return None
       df = pd.read_csv(fused_path)
       df['Score'] = df.apply(lambda r: 100 if r.get('AOI_Hit', False) else 10, axis=1)
       df_sorted = df.sort_values(by='Score', ascending=False)
       df_sorted.to_csv("scored_output.csv", index=False)
       print(f"✅ Scoring complete — {len(df_sorted)} rows saved to scored_output.csv")
       return df_sorted.head()

• The logger reads docs/training_mode_brief.json (if available) to pull the current Training Focus, overall posture, and nuclear/cyber/joint/fusion scores.
• It then prompts the trainee for:
  - name / callsign
  - optional session label/ID
  - self-assessed confidence (0–100)
  - a short situation summary (2–3 sentences)
  - key lessons learned (1–3 takeaways)
• Each run appends a new record to:
  - docs/training_sessions_log.json (machine-readable session history)
  - docs/training_sessions_log.txt (human-readable training log)
• The scores snapshot preserves Fusion Trust, Nuclear Score/Level, Cyber Threat Score/Level, and Joint Readiness at the time of the session, making this useful for tech school-style exercises, master’s-level labs, and future squadron training pilots.
• This module does not modify any pipeline configs or core fusion logic – it is a pure training/documentation layer that turns GLL into a trackable ISR training platform.

Day 67 – Self-Preservation Shield (SPS) – Module 2: Mutation Watcher

• Added sps_mutation_watcher.py:
  - Walks the src/ tree and records all .py files with:
      • relative path
      • file size
      • mtime
      • sha256 hash
  - On first run:
      • Creates docs/sps_file_snapshot.json as the baseline snapshot.
      • Writes docs/sps_mutation_report.json and .txt in BASELINE_CREATED mode.
  - On subsequent runs:
      • Compares current snapshot to previous baseline.
      • Reports:
          – new_files
          – removed_files
          – changed_files (size/hash differs)
          – zero_byte_files
          – critical_alerts for core modules (fusion, CLI, Golden Dome, base-defense, SPS modules).
      • Writes docs/sps_mutation_report.json and .txt in DIFF mode.

• Optional CLI integration:
  - Added Option 49) SPS Mutation Watcher Report in ghost_cli.py.
  - Running this option generates a fresh mutation report and prints the JSON/TXT paths.

• Operational impact:
  - GLL now has a file-level tamper/mutation awareness layer.
  - Any unexpected changes to fusion, nuclear, base-defense, or SPS modules can be detected and reconciled with git history.
  - This is a self-defense mechanism against accidental overwrites, bad copy–paste, or quiet sabotage.
